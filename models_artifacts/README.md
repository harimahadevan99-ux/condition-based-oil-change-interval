# models_artifacts

Place trained models, calibration files and parameter sets here
(for example `*.pkl`, `*.joblib`, `*.onnx`, `params.json`).

Large binaries should go to Git LFS or a model registry instead of plain Git.
This folder is empty on purpose in the first prototype version: the algorithms in
`src/core.py` are rule-based or physics-based and need no trained model yet.
